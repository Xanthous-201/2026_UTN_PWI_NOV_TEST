Como crear un repositorio?
git init

para dar seguimiento a los archivos git usamos 
git add .

para que los archivos  a los que git da seguimiento lo versione usamos 
  git commit -m 'message'

Para renombrar la rama maestra a main
git branch -M main

para saber que direccion remota esta conectado nuestro equipo
git remote -v 

para subir el ultmo commit en la nube 
gir remote -v
